# Hello to Hola website

This folder is ready to upload to a GitHub repository and deploy as a static site on Cloudflare Pages.

## Important upload detail

Upload the **contents of this folder** so that `index.html` is at the top level of the GitHub repository. Do not upload an extra enclosing folder.

## Included

- Rebranded, mobile-friendly home page
- Spanish and Catalan lesson pages
- About and 30-minute Calendly booking pages
- Guides hub and three complete SEO-focused guides
- Privacy, legal notice, and booking policy pages
- Sitemap, robots file, social sharing image, favicon, redirects, and security headers

## Updating the site

Edit the HTML files for text, `styles.css` for appearance, and files in `assets/images` for artwork. Commit changes to GitHub; Cloudflare Pages will redeploy automatically when connected to the repository.

## Before advertising

Review the privacy, legal notice, and booking policy pages and add any business-identification details required for your circumstances in Spain. The included text is a practical starting point, not legal advice.
